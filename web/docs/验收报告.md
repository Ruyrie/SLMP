## 二、工程与技术

- `web/` npm workspaces：`apps/user`、`apps/admin`、`packages/shared`、`e2e/tools`、`deploy`。
- Vue 3.5.43、Vuetify 3.13.6、TypeScript 6.0.3（strict）、Vite 8.3.3、Pinia 4.0.3、vue-router 5.3.1、axios、ECharts、hls.js、qrcode。
- 视觉基座直接从原型迁移：`tokens.css`、`zw.css`、`zw.js` 的 30 个 `zw-*` 组件、Material Symbols 字体；页面为 SFC。
- 请求层：统一 `{code,message,data,trace_id}` 解包、`ApiError`、40101 单飞刷新 + Web Locks、`X-Farm-Id`、`X-Client`、`Idempotency-Key`、上传进度、SSE 解析。
- 用户端 access token 只存内存，刷新令牌 HttpOnly Cookie；管理端 Cookie 会话 + 图形验证码 + 强制改密。
- 类型由运行中服务端 OpenAPI 生成，并把属性名统一为 snake_case（与真实 JSON 一致）；`npm run gen:api` 可重新生成。
- 部署：用户端 `/`、管理端 `/admin/`，Nginx 同源代理 `/api/v1`、`/admin/v1`、`/hls`；配置见 `web/deploy/nginx-zhimu-web.conf`，说明见 `web/deploy/README.md`。
