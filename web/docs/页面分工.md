# 页面分工与文件所有权（用户端）

> 每个代理只写自己名下的文件；路由文件只改自己负责的 `component` import，不改路径/名称/meta。
> 公共文件（`packages/shared`、`main.ts`、`App.vue`、`router/index.ts`、`api/client.ts`、`stores/auth|farm|ui|notice.ts`、登录页 `WU-A01`）由主控维护。
> 修改申请统一从其他页面跳转 `WU-U01` 并带 `biz_type`、`biz_id`、`action=create`，由 U1 在 U01 页面自动打开抽屉，不另建弹层。

## 原型与文档

- 原型：`原型导出/Web端/智牧通Web原型/pages/user/<页面编号>.js`，截图 `screenshots/<编号>-<状态>.png`。
- Web UI：`.tech-prep/text/Web端_用户端_模块XX-...-Web端UI设计文档.md`。
- App 规则：`.tech-prep/text/Android端_模块XX-...-UI设计文档.md`。
- 接口：`docs/api/endpoints.csv` + `server/zhimu-biz/.../biz/<模块>/controller|vo`。
