## 四、请求层

```ts
import { http } from '@/api/client'
import type { PageVO } from '@zmt/shared'

const data = await http().get<PageVO<PenVO>>('/pens', { page: 1, size: 20, keyword })
const detail = await http().post<PenDetailVO>(`/pens/${id}/status`, { enabled: false })
```

- 已自动带 `Authorization`、`X-Farm-Id`、`X-Client: WEB`、`Idempotency-Key`。
- `http().get/post/put/del/upload` 直接返回 `data`；失败抛 `ApiError`（`message`、`code`、`fieldErrors`、`traceId`）。
- 列表请求要支持取消：store 里保存 `AbortController`，新请求前 abort 上一次（`http().get(url, params, { signal })`）。
- 上传：`const form = new FormData(); form.append('file', file); form.append('scene', 'INSPECTION'); const file = await http().upload<FileVO>('/files', form, onProgress)`。
- AI SSE：`readSse(url, { method:'POST', headers:{Authorization..., 'X-Client':'WEB', 'X-Farm-Id':...}, body }, handlers, signal)`，`url` 用 `appConfig.apiBase + '/ai/...'`。
- 错误处理：`40001` 写字段错误，`40104` 由请求层统一回登录，`40302/3/4` 显示无权，`422xx` 显示横幅，其他 `useUiStore().toast(message, 'error')`。

## 五、store 模板（Pinia 选项式）

```ts
import { defineStore } from 'pinia'
import { http } from '@/api/client'
import type { ApiError, PageVO } from '@zmt/shared'

export type PageStatus = 'loading' | 'ready' | 'empty' | 'filtered_empty' | 'error' | 'forbidden'

export const usePenListStore = defineStore('penList', {
  state: () => ({
    query: { page: 1, size: 20, keyword: '' },
    list: [] as PenVO[],
    total: 0,
    tabCounts: {} as Record<string, number>,
    status: 'loading' as PageStatus,
    error: '',
    detail: null as PenDetailVO | null,
    drawer: false,
    submitting: false,
    form: { name: '', capacity: 0 },
    formErrors: {} as Record<string, string>
  }),
  getters: {
    isEmpty: (state) => state.status === 'empty',
    isFilteredEmpty: (state) => state.status === 'filtered_empty'
  },
  actions: {
    async fetchList() {
      this.status = this.list.length ? this.status : 'loading'
      this.error = ''
      try {
        const data = await http().get<PageVO<PenVO>>('/pens', { ...this.query })
        this.list = data.list || []
        this.total = data.total || 0
        this.tabCounts = data.tab_counts || {}
        this.status = this.list.length ? 'ready' : this.query.keyword ? 'filtered_empty' : 'empty'
      } catch (e) {
        const err = e as ApiError
        this.status = err.isForbidden ? 'forbidden' : 'error'
        this.error = err.message
      }
    }
  }
})
```

- 页面状态：`loading / ready / empty / filtered_empty / error / forbidden`；默认、空、失败、无权四态必须实现。
- 格式化在页面里用 `@zmt/shared` 的 `formatNumber/formatMoney/formatPercent/formatDate/formatDateTime/formatTime`，store 不拼显示文案。
- 金额/单价/成本/利润列用 `useRole().isManager` 控制渲染，员工视图直接不渲染。
- 切换养殖场后重新加载：`useFarmReload(fetchList)`。
- 页面 store 离开页面不清空；切换养殖场由 `revision` 触发重载。

## 八、角色与权限

- 角色：`owner` 所有者、`manager` 场长、`staff` 员工；员工不渲染金额、成本、盈亏、出栏单、行情、报表相关菜单/按钮/列/字段。
- 判断：`const { isManager, isStaff } = useRole()`；表格列定义用 `roles` 过滤。
- 服务端已按员工裁剪 VO 字段（不存在即不渲染），不要用 0 或“—”占位金额。
- 无权（40302/40303/40304）显示 `zw-empty` “无权查看”并写明原因，不要跳空白页。
