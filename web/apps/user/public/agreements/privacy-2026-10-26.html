隐私政策

版本：2026-10-26
更新及生效日期：2026年10月26日

本政策适用于智牧通当前项目试用服务，说明智牧通项目服务提供方（下称“我们”）如何处理您使用应用及配套网页时的信息，以及您可以如何管理这些信息。

在您同意前，不初始化高德地图定位和极光推送服务。阅读协议本身不会视为同意，也不会自动授予相机、麦克风、位置或通知权限。精确位置、照片、视频、语音及经营资料可能包含敏感信息，请仅在需要时提供。

一、我们处理哪些信息

1. 账号与身份核验

用于注册、登录、短信验证、密码重置、换绑及账号找回的信息包括手机号、验证码校验结果、密码验证信息、恢复码验证信息，以及您填写的姓名和头像。服务器通过密码摘要等方式校验凭据，不以业务页面展示您的登录密码。登录状态、设备信息和必要的操作记录用于账号安全、会话管理及异常排查。

2. 养殖场及业务资料

您主动填写的养殖场名称、地址或位置、成员信息，以及畜群、繁育、饲喂、巡检、健康、库存、财务等记录，会用于提供对应业务功能。记录中的姓名、手机号、影像或备注可能涉及个人信息。同一养殖场中有相应权限的成员可查看或处理相关资料，请避免提交无关人员信息。

3. 图片、视频与语音

拍照、扫码、录像、头像选择、记录附件、语音输入及 AI 图片分析会处理您主动拍摄、选择或提交的内容。系统媒体选择器仅向应用提供您选中的媒体；扫码时处理二维码内容。用于上传或分析的资料会发送到服务器及实现该功能所需的服务方，操作前请确认内容适合分享。

4. 位置、通知与运行信息

选择养殖场位置等功能可能使用您授权的位置或手动选择的地点。消息提醒使用账号关联关系、推送注册标识和通知内容。服务还可能处理 IP 地址、设备型号、系统及应用版本、网络状态、接口错误和必要的操作日志，用于通信、故障定位、安全防护和消息送达。

二、权限使用方式

  • 相机：拍照、扫描二维码和录像。拒绝后不能使用对应拍摄功能。
  • 麦克风：录像收音和语音输入。拒绝后可继续使用不需要录音的功能。
  • 位置：在地图中定位、选择地点。您可在系统中选择大致位置、精确位置或拒绝授权，定位能力会相应变化。
  • 通知：展示消息和业务提醒，可随时在系统设置中关闭。
  • 媒体选择：通过系统选择器读取您选定的照片或视频，不因选择单个文件而获得整个相册的任意访问权。

您可在设备“设置—应用—智牧通—权限/通知”中调整授权。撤回授权后，我们不再通过相应权限获取新信息，但不影响撤回前已依您授权完成的处理。仅关闭通知展示，不等同于删除账号或已保存的推送标识。

三、第三方 SDK 与服务

第三方数据范围受 SDK 版本、设备系统、已授予的权限及您使用的具体功能影响。以下为本项目已接入的主要服务：

高德地图、定位 SDK

提供方：高德软件有限公司、北京高德图强科技有限公司（对应地图、定位服务）。
用途：地图展示、地点选择及定位。
处理方式与信息：SDK 在设备端采集提供服务所需的位置、IP 地址、设备与系统参数、网络及 Wi-Fi/基站信息、传感器信息、应用信息和相关标识信息；具体可取得的信息依系统权限及 SDK 配置而定。精确位置需要您的位置授权。
启用时机：同意本政策后进行隐私初始化，使用地图定位功能时调用相应服务。
高德地图开放平台隐私权政策

极光推送 SDK（JPush / JCore）

提供方：深圳市和讯华谷信息技术有限公司。
用途：业务消息推送、设备与账号关联及送达维护。
处理方式与信息：SDK 处理推送注册标识、可用的设备标识、设备与系统信息、应用信息、网络信息及推送日志；依设备权限和 SDK 配置，相关信息可能包括 Android ID、OAID、IP 地址和网络状态。推送服务可能在前台或后台维持连接。
启用时机：同意本政策后初始化；通知展示受系统通知授权控制。
极光隐私政策

短信验证与 AI 辅助服务

短信验证启用时，由服务端向阿里云号码认证服务提交手机号及必要的验证参数。AI 问答、图片分析及语音识别启用时，问题文本、上下文、您选择的图片或音频及生成任务所需的业务摘要可能发送至阿里云百炼；部分任务可使用 DeepSeek 作为备用服务。仅为实现您选择的功能传输相关内容，请勿提交密码、验证码或无关敏感资料。

这些服务通过后端接口调用，不是额外的手机权限。相应服务方也会按其规则处理接收到的信息。详情可查阅阿里云官方网站及DeepSeek 官方网站公布的相关服务与隐私说明。

四、信息保存、保护与删除

账号资料、业务记录、媒体附件及必要日志保存在提供智牧通服务的服务器和存储系统中；设备中可能保存登录凭据、设置和展示缓存。我们采用权限控制、登录校验、密码摘要及必要的访问限制等措施保护信息，但任何系统都无法保证绝对安全。请勿在项目试用环境提交与试用无关的敏感资料。

我们按实现功能、安全维护及依法履行义务所需的期限保留数据。注销后个人数据按注销清单执行清理；关联养殖场的业务记录可能保留并将登记人标记为“已注销用户”。当前账号手机号保留期为30天，停用养殖场保留期为180天。备份和必要安全记录可能按对应清理周期处理；法律要求保留的部分依法保留。

除提供服务所必需、取得您的授权或依法履行义务等情形外，我们不会向无关第三方提供您的个人信息。发生安全事件时，我们会采取处置措施，并根据事件及适用要求通知受影响用户。

五、您的选择和权利

您可在个人资料和账号设置中查看或修改已开放编辑的信息、修改密码、管理账号，或发起注销；可通过系统设置撤回设备权限。若希望进一步访问、更正、复制或删除个人信息，或撤回对持续使用服务的同意，可联系向您提供本应用的项目负责人；所属养殖场管理员可协助转交请求。我们会在核实必要身份信息后处理，并说明无法立即办理的原因。

删除应用不会自动注销账号或删除服务器数据。注销前请先阅读影响范围，保存必要资料并妥善处理养殖场权限。拒绝本政策时，可以选择退出应用。

六、未成年人

本服务面向养殖经营及相关学习场景，不专门面向儿童。未成年人应在监护人知情指导下使用；不满14周岁的用户请勿自行注册或提交个人信息。如发现未经适当授权处理了未成年人信息，可通过项目负责人请求核实与删除。

七、政策更新与联系

本页面显示当前政策版本。涉及处理目的、信息种类或第三方服务等重要变化时，我们会更新政策，并在需要时提示您重新阅读和同意。关于本政策或数据处理的疑问，请联系向您提供智牧通服务的项目负责人。
