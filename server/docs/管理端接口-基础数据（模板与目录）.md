# 管理端接口 · 基础数据（模板与目录）

> 范围：管理端-03 `WA-D02 免疫程序模板`、`WA-D03 兽药疫苗目录`、`WA-D04 巡检项目模板`。
> 依据：《管理端-03 基础数据-服务端技术准备文档》2.3–2.7、`Web端_管理端_Web管理端-03-基础数据-UI设计文档`、`V1_23_1` / `V2_05`–`V2_08_1` 表结构与初始化数据。
> 实现分支：`web/admin-base`。WA-D01（品类品种与标准）、WA-D05（其他字典）已由 3A 实现，本文不重复。

## 0. 通用约定

| 项目 | 约定 |
|---|---|
| 前缀 | 所有接口 `/admin/v1/...`；管理端会话 Cookie 鉴权，Controller 取 `AdminContext` |
| 响应 | `{code, message, data, trace_id}`；成功 `code=0`、`message` 为本文中文案；HTTP 200 |
| JSON | 全部 snake_case；时间为北京时间，datetime `yyyy-MM-dd HH:mm:ss`、date `yyyy-MM-dd` |
| 分页 | `page` 从 1 开始，`size` 默认 20、最大 100；`PageVO` 字段 `list/total/page/size/has_more/tab_counts` |
| 版本 | 模板、目录、禁用药的写操作必须带记录 `version`；不一致返回 `40902 内容已更新，请刷新后再修改` |
| 幂等 | 标 `幂等键` 的接口要求 `Idempotency-Key` 请求头（管理端前缀 `idem:a{admin_id}:{key}`） |
| 权限 | 类级 `WA-Dxx:VIEW`；写接口方法级 `WA-Dxx:HANDLE`。无权限返回 `40308` |
| 留痕 | 全部写接口在同一事务写 `t_operation_log`（`op_type = BASE_IMMUNE_TEMPLATE / BASE_INSPECT_TEMPLATE / BASE_DRUG_CATALOG / BASE_BANNED_DRUG / BASE_LOT_RECALL`） |
| 空值 | 值为 null 的字段不输出；集合为空输出 `[]` |
| 字段错误 | `40001` 时 `data.field_errors = [{field, message}]`，`field` 为请求体 snake_case 字段名 |

### 0.1 通用错误码

| 错误码 | 场景 | 文案 |
|---|---|---|
| 40001 | 参数校验 | 按接口逐字给出（见各接口） |
| 40004 | 原因 / 说明为空 | `请填写停用原因`、`请填写修改说明`、`请填写修改原因`、`请填写列入原因` |
| 40106 | 管理员会话超时 | 登录已超时，请重新登录 |
| 40308 | 无权限 | 你没有该页面的操作权限，如需处理请联系超级管理员 |
| 40401 | 记录不存在 | 记录不存在或无权查看 |
| 40902 | 版本冲突 | 内容已更新，请刷新后再修改 |
| 40903 | 状态已变化 | 按接口逐字给出（无草稿、重复停用、已停用的批号等） |
| 40905 | 名称重复 | 按接口逐字给出 |
| 42203 | 禁用药 | 该药品属于禁用兽药，不能使用 / `{名称}为禁用药，不能加入目录` / 该药品已列为禁用药，不能启用 |
| 42207 | 状态不允许 | 已发布的项目不能删除，请停用 |

## 1.4 ADM-D16 新建 / 复制模板（幂等键）

`POST /admin/v1/immune-templates`

```json
{
  "breed_id": 1103,
  "name": "大白育肥猪",
  "copy_from_template_id": 21
}
```

| 字段 | 类型 | 必填 | 校验 |
|---|---|---|---|
| breed_id | long | 是 | 启用品种且尚无模板，否则 40905 `该品种已有模板` |
| name | string | 否 | ≤30 字；为空默认“品种名 + 品类名” |
| copy_from_template_id | long | 否 | 已发布模板；复制其线上项目为草稿，全部标 `ADDED`；未发布返回 40001 `请选择已发布的模板` |

响应 `data` 为 D15 结构；成功文案 `已保存“大白育肥猪”`。

## 1.5 ADM-D17 添加项目（幂等键）

`POST /admin/v1/immune-templates/{id}/items`

```json
{
  "vaccine_id": 7003,
  "dose_round": "二免",
  "schedule_type": "BY_DAY_AGE",
  "day_age": 85,
  "dose": 2.00,
  "dose_unit": "DOSE_PER_HEAD",
  "vaccinate_method_code": "IM",
  "remark": "妊娠后期母猪顺延",
  "version": 12
}
```

| 字段 | 类型 | 必填 | 校验 / 文案 |
|---|---|---|---|
| vaccine_id | long | 是 | 目录中启用、未列入禁用药的疫苗，且品种畜种 `applicable = 1`；否则 `请选择疫苗` / `所选疫苗已停用，请重新选择` / `所选疫苗不适用于该畜种`；禁用药 42203 |
| dose_round | string | 是 | 1–10 字，同一草稿“疫苗 + 免次”唯一，重复 40905 `已有“口蹄疫灭活疫苗 · 二免”` |
| schedule_type | string | 是 | `BY_DAY_AGE` / `BY_DATE` |
| day_age | int | 按日龄必填 | 1–999，否则 40001 `接种日龄必须在 1–999 之间` |
| plan_month / plan_day | int | 按日期必填 | 合法月日（不允许 2 月 29 日），否则 `请选择正确的日期` |
| advance_days | int | 按日期必填 | 1–60，否则 `提前生成必须在 1–60 天之间` |
| dose | decimal | 是 | > 0、≤2 位小数；否则 `剂量必须大于 0` |
| dose_unit | string | 是 | `DOSE_PER_HEAD` / `ML_PER_HEAD` / `DOSE_PER_BIRD` |
| vaccinate_method_code | string | 是 | 启用字典 `VACCINATE_METHOD` 且适用该畜种，否则 `该接种方式不适用于猪` |
| remark | string | 否 | ≤100 字 |
| version | int | 是 | 模板当前 `version`；首次修改自动创建草稿 |

响应 `data` 为 `ImmuneItemVO`；成功文案 `已保存，发布后生效`。删除过相同“疫苗 + 免次”时恢复原行而非新增。

## 1.6 ADM-D18 编辑项目

`PUT /admin/v1/immune-templates/{id}/items/{item_id}`，请求体同 D17（含 `version`）。

- `item_id` 可以是草稿项 ID，也可以是尚无草稿时的线上项 ID（按 `source_item_id` 对应）。
- 保存后按与线上值比较自动标 `NONE` / `MODIFIED`。
- 成功文案 `已保存，发布后生效`。

## 1.7 ADM-D19 删除项目

`DELETE /admin/v1/immune-templates/{id}/items/{item_id}?version=12`

- 已发布来源项标记 `DELETED`，发布时物理移除；`ADDED` 项立即物理删除。
- 响应 `data = null`；成功文案 `已删除，发布后生效`。

## 1.8 ADM-D20 调整顺序

`PUT /admin/v1/immune-templates/{id}/items/order`

```json
{ "item_ids": [2101, 2102, 2103], "version": 12 }
```

`item_ids` 必须是草稿全部未删除项，否则 40001 `请提交草稿全部未删除项目`；成功文案 `已调整顺序，发布后生效`。

## 1.9 ADM-D21 发布修改

`POST /admin/v1/immune-templates/{id}/publish`

```json
{ "change_note": "按新版免疫程序建议，伪狂犬加强免疫推迟到 120 日龄", "version": 12 }
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| change_note | string | 是 | 1–100 字，为空 40004 `请填写修改说明` |
| version | int | 是 | 模板 `version` |

规则：必须有草稿且至少 1 个未删除项目；再次校验每个疫苗仍启用、未列入禁用药。发布后 `version_no = 线上版本 + 1`，草稿版本转 `PUBLISHED`，原线上版本转 `SUPERSEDED`，模板 `online_version_no` 更新、`has_draft=false`、重算 `has_by_date`。只对之后入栏的批次生效。

响应 `data`（`TemplateVersionVO`）：

```json
{
  "version_id": 211,
  "version_no": 5,
  "status": "PUBLISHED",
  "status_text": "线上",
  "change_note": "按新版免疫程序建议，伪狂犬加强免疫推迟到 120 日龄",
  "item_count": 9,
  "published_by_name": "周敏",
  "published_at": "2026-10-23 20:00:00",
  "items": [ { "item_id": 2101, "vaccine_name": "猪瘟活疫苗", "dose_round": "首免" } ]
}
```

成功文案 `已发布第 5 版，之后入栏的批次按新模板生成免疫计划`。

## 1.10 ADM-D22 放弃修改

`POST /admin/v1/immune-templates/{id}/discard`

```json
{ "version": 12 }
```

没有草稿返回 40903 `没有未发布的修改，请刷新`；成功文案 `已放弃未发布的修改`。

## 1.11 ADM-D23 版本记录

`GET /admin/v1/immune-templates/{id}/versions`

响应 `data` 为 `TemplateVersionVO[]`，按版本号倒序，`items` 为该版本项目（含变更标记），发布人姓名由 `t_admin` 回填。

## 1.12 ADM-D23A 回退到历史版本（扩展接口）

服务端技术准备文档未给 D02 回退编号；为满足“版本列表、回退到历史版本”，新增本接口。语义：把指定历史版本的项目复制为**新草稿**（`change_type=NONE`），发布后生效；不会直接改线上版本。

`POST /admin/v1/immune-templates/{id}/rollback`

```json
{ "target_version_no": 3, "version": 12 }
```

- 目标版本不存在 40401；目标即当前线上版本 40903 `当前已是第 X 版，不需要回退`。
- 已存在草稿会被替换（放弃后重建）。
- 响应为 D15 详情；成功文案 `已回退到第 3 版的内容，发布后生效`。

`GET /admin/v1/inspect-templates/{id}/versions`

响应 `TemplateVersionVO[]`（按版本号倒序），`items` 为该项目版本的项目与结果。

## 3.12 ADM-D48A 回退到历史版本（扩展接口）

`POST /admin/v1/inspect-templates/{id}/rollback`

```json
{ "target_version_no": 1, "version": 5 }
```

语义同 D23A：历史版本项目与结果复制为新草稿（`NONE`），发布后生效；目标即当前线上版本返回 40903；成功文案 `已回退到第 1 版的内容，发布后生效`。
