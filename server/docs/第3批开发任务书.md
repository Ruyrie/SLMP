## 二、所有工作包必须遵守

1. 先读 `server/docs/服务端开发约定.md` 第一至五节；JSON 规则、错误码、多租户、分页、时间格式全部照做。
2. **不改 App 任何文件**；不改 `pom.xml`、`application*.yml`、`zhimu-common`、`zhimu-framework`、`zhimu-integration`、别人的模块、`server/docs`。
3. 新增错误码先查 `ErrorCode`；大多数业务码已存在（42201–42211、40303–40307、41001 等）。确实要加时只加在 `zhimu-common/error/ErrorCode.java`，并在报告里列出，合并时统一处理。
4. 接口路径、方法、请求字段、响应 JSON 字段名/类型**逐一对齐 App**。每个接口至少对照一个 `routes.json` 里的响应样例；样例里出现而文档没有的字段要补。
5. 查询接口 `data` 不能为 null；空列表返回 `[]`；分页用 `PageVO`（list/total/page/size/has_more，必要时继承加 tab_counts）。
6. 养殖场表实体标 `@FarmScoped`；跨场查询用 `TenantSkip`；写操作要有 `version` 乐观锁（App 传 version 的接口）。
7. 模块之间只通过对方 `api` 包的 Service 接口调用，不直接读对方 Mapper。
8. 每个写接口按 App 的用法处理幂等：App 传 `Idempotency-Key` 的用 `@Idempotent`；App 用 `client_request_id` 的按唯一索引防重。
9. 单测用 JUnit5 + Mockito + AssertJ；Controller 用 standalone MockMvc。不要写完整 `@SpringBootTest`。
10. 员工字段裁剪：金额/单价/成本/利润类字段标 `@ManagerView`；员工无权的接口用 `@FarmRoles`。

## 六、验收（每个工作包）

```powershell
# 编译
mvn -q -B -pl zhimu-biz -am -DskipTests compile

# 单测（示例）
$env:TEST_DB_NAME='zhimu_test_m04'; $env:TEST_REDIS_DATABASE='4'
mvn -q -B -pl zhimu-biz -am test -Dtest='Herd*Test' -Dsurefire.failIfNoSpecifiedTests=false

# 启动冒烟（可选，能起就做）
mvn -q -B -pl zhimu-app -am -DskipTests package
```

- 所有新增/修改代码必须编译通过；本包单测全绿。
- 接口路径覆盖率：本包 `routes.json` 里的每个 method+path 都要有对应 Controller 映射（可在报告里贴对照表）。
- 响应形状：每个接口至少一个测试断言关键字段（`jsonPath`），字段名以 mock 为准。
- 不要求全量 `mvn verify`（合并后主代理跑）。
