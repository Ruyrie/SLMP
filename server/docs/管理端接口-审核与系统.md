# 管理端接口契约 · 审核中心 + 用户与系统

> 范围：WA-R01 养殖场注册审核、WA-R02 资料变更审核、WA-R03 修改申请审核、WA-R04 账号找回，以及 WA-S02 平台概览、WA-S03 用户账号、WA-S04 养殖场管理。
> 代码位置：`com.zhimu.server.admin.audit`、`com.zhimu.server.admin.system`；所有路径前缀 `/admin/v1`。
> 统一响应：`{code, message, data, trace_id}`；JSON 一律 snake_case；时间为北京时间（datetime `yyyy-MM-dd HH:mm:ss`、date `yyyy-MM-dd`）；手机号除另行说明外均打码为 `138****6620`。
> 分页：`page` 从 1 开始，`size` 默认 20、最大 100；列表统一为 `{list,total,page,size,has_more,tab_counts}`，部分页面在 list 同级追加 `overdue_count`、`stats` 等字段。

## 二、ADM-R01 四类待审核数

`GET /admin/v1/audit/pending-counts`，轮询接口不续期会话。

响应 data：

```json
{
  "farm_audit": 1,
  "farm_change": 0,
  "change_request": 0,
  "account_recovery": 0,
  "overdue_total": 1,
  "items": [
    {"queue":"FARM_AUDIT","count":1,"earliest_at":"2026-10-19 08:46:00","overdue_count":1},
    {"queue":"FARM_CHANGE","count":0,"overdue_count":0},
    {"queue":"CHANGE_REQUEST","count":0,"overdue_count":0},
    {"queue":"ACCOUNT_RECOVERY","count":0,"overdue_count":0}
  ],
  "sellable_date_count": 0
}
```

- 没有某页 VIEW 权限时对应顶层字段和 `items` 项不输出；没有任何审核页 VIEW 时 40308“你没有审核中心的查看权限”。
- 账号找回只统计 `status=PENDING` 且新手机号已验证（恢复码已核对正确）的申请；没有恢复码的申请不会进入该表。
- 超过 48 小时：提交时间早于当前时间 − 48 小时，恰好 48 小时不算；`overdue_total` 为所有有权限队列之和。

错误码：40106、40308。

### R02 列表

| province_code | string | 否 | 2–6 位行政区划码，按前 2 位匹配省份 |

### R04 通过

`POST /admin/v1/farm-audits/{id}/approve`

```json
{"audit_opinion":"资质图清晰完整，地图位置与地址一致。","version":0}
```

- `audit_opinion` 去首尾空格后 1–200 字，必填。
- 响应 data：`{"target_name":"北湾牛场","notified_names":["王建国"]}`；message“已通过北湾牛场的注册申请，结果已发到王建国的消息中心”。
- 错误码：40004 请填写审核意见；40001 超过 200 字；40902 内容已更新，请刷新后再审核；40903 已由其他管理员处理；41001 申请已被所有者删除；40401。

### R05 驳回

`POST /admin/v1/farm-audits/{id}/reject`

```json
{"reject_reason":"资质图中的证件照片反光，看不清编号和有效期。","reshoot_file_ids":[5521],"version":0}
```

- `reject_reason` 必填 1–200 字；`reshoot_file_ids` 最多 9 个，必须属于本次提交快照中的资质图。
- 响应 data 同 R04；message“已驳回北湾牛场的注册申请，原因已发到王建国的消息中心”。
- 错误码：40004 请填写驳回原因；40001 需重拍的资质图不属于本次提交；40902/40903/41001/40401 同 R04。

### S17 冻结、S18 解冻

`POST /admin/v1/farms/{id}/freeze`

```json
{"reason":"属地畜牧部门通报：动物防疫条件合格证已被注销。","sms_owner":false,"version":3}
```

响应 data：`{"member_count":3,"farm_name":"东山猪场"}`。message“已冻结东山猪场，原因已发到 3 名成员的消息中心”。
- 只能冻结已通过审核且未冻结的养殖场；写 FARM_FREEZE / FREEZE 日志；冻结原因发全部在场成员。

## 十一、已知取舍

1. **R03 影响行**：公共 `ChangeRequestHandler` 没有 `estimateImpact` 方法，`impact.rows` 只能读提交/审核时写入 `impact_json` 的快照；没有快照时返回空数组并给出重算标签。若前端必须展示“当前/通过后”三列表格，需后续给 handler 增加估算接口。
2. **R04 结果短信**：通过/驳回后申请进入 `result_sms_status=PENDING`，实际短信发送与重试由模块01 的后续任务完成；本期管理端只负责状态流转和留痕。
3. **R04 未实现接口**：R18–R24（重发、代登记、校验记录、导出、批次汇总、查看完整号码）不在本期范围；前端“校验记录”标签与“代为登记”按钮暂不接后端。
4. **地图坐标**：S07 使用同区划养殖场坐标平均值，未调用高德区划中心点；生产配置高德 Key 后可替换为区划中心点。
5. **导出**：导出为同步生成，最多 10,000 条；依赖 MinIO 可用，失败返回 50301。
6. **重复统计查询**：S06 为各块独立容错，`farm_stat`/`user_stat` 在活跃度块会再次查询，数据量大时可后续合并为一次查询并缓存 60 秒。
7. **通知接收人**：R12 通过后返回 `notified_names` 只含提交人（现有 `ChangeRequestAdminService` 的消息实现只发提交人）；所有者是否需要另外收到消息，需主控确认后再改公共消息链路。
