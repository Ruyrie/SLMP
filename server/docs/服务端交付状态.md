## 三、启动与联调

```powershell
cd server
# 1. 中间件
powershell -ExecutionPolicy Bypass -File .\tools\start-dev.ps1
# 2. 配置 .env.local（DB/REDIS/MINIO/JWT；AI/短信/推送按需）
# 3. 启动
mvn -pl zhimu-app -am spring-boot:run
```

- 接口文档：<http://127.0.0.1:8080/swagger-ui.html>
- 示例账号：`13800006620 / Zmt12345`（所有者王建国），`13700005678`（员工李明）
- 演示日期：`ZMT_FIXED_DATE=2026-10-19`（只在 dev/test）
- App 切换：见 `docs/App切换真实服务端.md`，**必须 HTTPS**

> 已执行过旧版 `V2_07/V9_07/V9_08/V9_10` 的本地库，脚本内容变更后需要
> `mvn -pl zhimu-app flyway:repair` 或删除 `zhimu` 库重建。
