# 管理端接口 · 内容运营（通知 / 行情 / AI 问答）

> 范围：WA-C01 通知发布（ADM-C01–C10）、WA-C02 市场行情发布（ADM-C11–C22）、WA-C05 AI 问答与更正（ADM-C57–C65）。
> 适用分支：`web/admin-content`。所有路径以 `/admin/v1` 开头；管理端鉴权由框架 Cookie 拦截器完成，权限点写在每个接口上。
> JSON 一律 snake_case；时间 `yyyy-MM-dd HH:mm:ss`、日期 `yyyy-MM-dd`、比例 `0.7400`；分页 `page` 从 1 开始，默认 20，最大 100。
> 成功响应统一 `{code:0, message:"ok", data, trace_id}`；列表 `data = {list,total,page,size,has_more,tab_counts?}`；空列表返回 `[]`，不返回 204。
> 本文件对应实现：`server/zhimu-biz/src/main/java/com/zhimu/server/admin/content/`。

## 一、通用约定

### 1.1 权限与通用错误

| 权限点 | 页面 | 说明 |
|---|---|---|
| `WA-C01:VIEW` / `WA-C01:HANDLE` | WA-C01 | 查看 / 新建、编辑、发送、取消、撤回、删除草稿、导出 |
| `WA-C02:VIEW` / `WA-C02:HANDLE` | WA-C02 | 查看 / 录入发布、更正、复核、撤销、导入 |
| `WA-C05:VIEW` / `WA-C05:HANDLE` | WA-C05 | 查看 / 发布、修改、撤回更正说明、无需处理、导出 |

| 错误码 | 场景 | 文案 |
|---|---|---|
| 40001 | 参数校验 | 具体文案见各接口；`data.field_errors = [{field, message}]`，field 用 snake_case |
| 40002 | 配图类型 / 大小不符 | 只支持 JPG 或 PNG 图片，单张不超过 5MB |
| 40004 | 原因为空 | 请填写取消原因 / 请填写撤回原因 / 请填写复核说明 / 请填写更正原因 / 请填写撤回原因 |
| 40106 | 管理端会话过期 | 登录已超时，请重新登录 |
| 40303 | 复核人是录入人 / 不是超级管理员改行情配置 | 复核人不能是录入人；只有超级管理员可以修改发布配置 |
| 40308 | 无页面权限 | 你没有该页面的操作权限，如需处理请联系超级管理员 |
| 40401 | 记录不存在 | 记录不存在或已删除 |
| 40902 | 版本冲突 | 内容已更新，请刷新后再修改 |
| 40903 | 状态已变化 | 具体文案见各接口 |
| 41001 | 已删除草稿 | 该记录已被删除 |
| 50001 | 服务异常 | 出了点问题，请稍后重试 |

### 1.2 分页

请求参数 `page`（默认 1）、`size`（默认 20，最大 100）。响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "list": [],
    "total": 0,
    "page": 1,
    "size": 20,
    "has_more": false,
    "tab_counts": { "ALL": 0 }
  },
  "trace_id": "..."
}
```

`tab_counts` 的键按页面约定固定；计数与列表使用同一组筛选条件（状态分段除外）。

## 二、WA-C01 通知发布

### 2.0 数据模型

**通知状态**：`DRAFT` 草稿、`SCHEDULED` 待发送、`SENT` 已发送、`REVOKED` 已撤回、`CANCELED` 已取消。
**级别**：`IMPORTANT` 重要、`NORMAL` 普通。**范围**：`ALL` 全部用户、`CONDITION` 按条件、`FARM` 指定养殖场。
**提交动作**：`submit_action = DRAFT / SCHEDULE / SEND_NOW`。

通知列表行 `NoticeRowVO`：

| 字段 | 类型 | 说明 |
|---|---|---|
| id | long | 通知 ID |
| title | string | 标题 |
| image_count | int | 配图数（0/1） |
| content_length | int | 去标签后的正文字数 |
| level / level_text | string | `IMPORTANT/NORMAL`、中文 |
| scope_type / scope_text | string | 范围编码、页面显示文字（“全部用户”“所有者、场长”“指定养殖场”） |
| condition_text | string? | 条件补充：地区、品类或养殖场名称；`ALL` 为空 |
| account_count | int | 草稿/待发送为预计送达，已发送/已撤回为实际送达 |
| status / status_text | string | 状态编码、中文 |
| scheduled_at / sent_at / revoked_at / canceled_at | datetime? | 时间列 |
| read_rate | decimal? | 仅 `SENT` 有，已读 ÷ 送达，4 位 |
| read_before_revoke | int? | 仅已撤回有 |
| creator_name | string | 创建人姓名 |
| updated_at | datetime | 最近更新时间 |

`NoticeDetailVO` 追加：

| 字段 | 类型 | 说明 |
|---|---|---|
| content | string? | 受限 HTML（段落、换行、加粗、编号/项目列表） |
| image | FileVO? | `{file_id,url,thumb_url,media_type,mime_type,size,width,height,status}` |
| send_mode / send_mode_text | string | `NOW/SCHEDULED`、立即发送/定时发送 |
| roles | string[] | 条件角色 |
| province_codes | string[] | 条件省级码 |
| category_ids | long[] | 条件品类 |
| farms | `{farm_id,name}[]` | 指定养殖场回填 |
| est_account_count / est_farm_count | int | 保存时预计 |
| delivered_count / read_count / unread_count / push_open_count | int? | 已发送后才有 |
| stat_at | datetime? | 统计时间 |
| role_stats | `[{role,role_text,read,delivered,rate}]` | 按角色阅读 |
| creator / sender | `{name,at}` | 创建人、发送人 |
| revoked_by_name / revoke_reason / canceled_by_name / cancel_reason | string? | 撤回/取消 |
| timeline | `[{action,action_text,time,admin_name,desc}]` | 操作记录 |
| version | int | 乐观锁 |

### 2.1 ADM-C01 通知指标卡

- `GET /admin/v1/notices/summary`
- 权限：`WA-C01:VIEW`
- 参数：无
- 响应 `data`：

```json
{
  "month_sent_count": 4,
  "month_important_count": 1,
  "month_revoked_count": 1,
  "scheduled_count": 1,
  "draft_count": 1,
  "avg_read_rate_30d": 0.6610,
  "next_scheduled_at": "2026-10-20 08:00:00"
}
```

口径：本月按 `sent_at`（含已撤回）；平均阅读率取近 30 天 `SENT` 的已读合计 ÷ 送达合计（不含已撤回）。失败：40106、40308、50001。

### 2.2 ADM-C02 通知列表与分段计数

- `GET /admin/v1/notices`
- 权限：`WA-C01:VIEW`
- Query：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| status | string | 否 | 不传 = 全部；`DRAFT/SCHEDULED/SENT/REVOKED/CANCELED` |
| level | string | 否 | `IMPORTANT/NORMAL` |
| scope_type | string | 否 | `ALL/CONDITION/FARM` |
| keyword | string | 否 | 标题模糊，≤50 字 |
| page / size | int | 否 | 分页 |

- 排序：`updated_at` 倒序，再 `id` 倒序。
- `tab_counts`：`ALL/DRAFT/SCHEDULED/SENT/REVOKED/CANCELED`，受 `level/scope_type/keyword` 影响，不受 `status` 影响。
- 响应 `PageVO<NoticeRowVO>`；字段见 2.0。
- 错误：40001（关键词超长）；40106；40308；50001。

### 2.3 ADM-C03 预计送达

- `POST /admin/v1/notices/audience-estimate`
- 权限：`WA-C01:HANDLE`
- Request：

```json
{
  "scope_type": "CONDITION",
  "roles": ["OWNER", "MANAGER"],
  "province_codes": ["150000", "230000"],
  "category_ids": [],
  "farm_ids": []
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| scope_type | 是 | `ALL/CONDITION/FARM` |
| roles | CONDITION 时是 | 至少 1 个：`OWNER/MANAGER/STAFF` |
| province_codes | 否 | 6 位省级码，≤34 个；空 = 全部地区 |
| category_ids | 否 | 品类 ID；空 = 全部品类 |
| farm_ids | FARM 时是 | 1–200 个已通过审核的养殖场 |

- 响应：

```json
{ "account_count": 642, "farm_count": 231 }
```

- 错误：40001“至少选择一个角色”“请选择至少一个养殖场”“一次最多选择 200 个养殖场”；40106；40308；50001。
- 说明：ALL 包含未加入养殖场的账号，其 `role_snapshot` 记为 `NONE`；CONDITION 只统计已通过审核、未停用、未冻结养殖场的 ACTIVE 成员；FARM 取所选养殖场全部 ACTIVE 成员，`farm_id` 取交集最小 ID。

### 2.4 ADM-C04 新建通知

- `POST /admin/v1/notices`
- Header：`Idempotency-Key` 必填（框架 `@Idempotent(required = true)`）
- 权限：`WA-C01:HANDLE`
- Request：

```json
{
  "submit_action": "SCHEDULE",
  "level": "IMPORTANT",
  "title": "寒潮降温防护提醒",
  "content": "<p>各养殖场：</p><p>请做好防寒准备。</p><ol><li>检查门窗。</li></ol>",
  "image_file_id": 7001,
  "scope_type": "CONDITION",
  "roles": ["OWNER", "MANAGER"],
  "province_codes": ["150000", "230000"],
  "category_ids": [],
  "farm_ids": [],
  "scheduled_at": "2026-10-20 08:00:00",
  "copied_from_id": null
}
```

- 校验：`submit_action` 必填；`title` 去空白后 1–50 字（草稿也只校验本项）；`level` 默认 `NORMAL`；SCHEDULE/SEND_NOW 时 `content` 清洗后 1–2000 字、范围必填；SCHEDULE 时 `scheduled_at ≥ 当前北京时间 + 10 分钟`；配图必须为 `NOTICE_IMAGE` 且 READY、JPG/PNG、≤5MB；`copied_from_id` 必须存在。
- 响应 `NoticeVO`：

```json
{
  "id": 12,
  "status": "SCHEDULED",
  "status_text": "待发送",
  "scheduled_at": "2026-10-20 08:00:00",
  "sent_at": null,
  "est_account_count": 642,
  "delivered_count": 0,
  "revoked_at": null,
  "read_before_revoke": null,
  "version": 0
}
```

- 成功提示：`已保存草稿` / `已设为定时发送，10月20日 08:00 发送` / `已发送，正在推送给 642 个账号`。
- 错误：40001“请填写通知标题”“标题不能超过 50 字”“请填写正文”“正文不能超过 2000 字”“定时发送时间至少在 10 分钟以后”“至少选择一个角色”“请选择至少一个养殖场”“当前条件下没有可送达的账号”；40002 配图；40901 幂等处理中；40106；40308。

### 2.5 ADM-C05 编辑通知

- `PUT /admin/v1/notices/{id}`
- 权限：`WA-C01:HANDLE`
- 请求同 ADM-C04，另加 `version`（必填，与库中一致）。只允许编辑 `DRAFT`、`SCHEDULED`。
- 响应 `NoticeVO`。`SCHEDULE→DRAFT` 会清空定时时间；`SCHEDULE/SEND_NOW` 重新做全部校验。
- 错误：40902“内容已更新，请刷新后再修改”；40903“这条通知已发送或已取消，不能再编辑，列表已刷新”；其余同 ADM-C04。

### 2.7 ADM-C07 取消发送

- `POST /admin/v1/notices/{id}/cancel`
- 权限：`WA-C01:HANDLE`
- Request：`{ "reason": "时间调整", "version": 2 }`
- 前置：`SCHEDULED`。响应 `NoticeVO`（`status=CANCELED`）。
- 成功提示：`已取消发送`。
- 错误：40004“请填写取消原因”；40903“这条通知已到点发送，不能取消；如需收回请撤回”；40902；40401。

### 2.8 ADM-C08 撤回发送

- `POST /admin/v1/notices/{id}/revoke`
- 权限：`WA-C01:HANDLE`
- Request：`{ "reason": "通知里的发布时间写错了", "version": 3 }`
- 前置：`SENT`。响应 `NoticeVO`（`status=REVOKED`，`revoked_at`、`read_before_revoke` 有值）。
- 副作用：调用 `MessageService.hideUnreadByBiz` 隐藏未读 `t_message` 并取消未发出的延后推送；`t_notice_recipient.is_hidden=1`；已读消息保留。
- 成功提示：`已撤回这条通知`。
- 错误：40004“请填写撤回原因”；40903“只有已发送的通知可以撤回”；40902；40401。

### 2.9 ADM-C09 删除草稿

- `DELETE /admin/v1/notices/{id}?version=2`
- 权限：`WA-C01:HANDLE`
- 前置：`DRAFT`。`version` 选填，传了就必须一致。逻辑删除。
- 成功提示：`已删除草稿`。
- 错误：40903“只能删除草稿”；40902；41001；40401。

### 2.10 ADM-C10 导出阅读数据

- `POST /admin/v1/notices/read-stats/export`
- 权限：`WA-C01:HANDLE`
- Body 同 ADM-C02 的筛选条件（`status` 会被忽略，只导出 `SENT/REVOKED`）。
- 响应：

```json
{
  "file_id": 9001,
  "file_name": "通知阅读数据_20261019.xlsx",
  "status": "READY",
  "url": "http://.../download?...",
  "row_count": 11
}
```

- 列：标题、级别、接收范围、发送时间、送达、已读、阅读率、所有者阅读率、场长阅读率、员工阅读率、推送点开、撤回时间。
- 行数 > 5 万返回 40001“导出超过 5 万行，请缩小筛选范围”。
- 说明：当前实现为同步生成 xlsx 并写 `t_file`（scene=EXPORT），返回 10 分钟有效下载地址；`url` 可直接下载，`file_id` 便于后续接 ADM-S37/S39。

### 2.11 养殖场下拉（补充接口）

- `GET /admin/v1/notices/farm-options?keyword=东山`
- 权限：`WA-C01:HANDLE`
- 响应 `[{farm_id,name}]`，只返回已通过审核、未删除的养殖场，最多 50 条。

## 三、WA-C02 市场行情发布

### 3.0 数据模型与规则

- 价格按“省份 × 品类 × 品种 × 价格类型”唯一定位；`breed_id=0` 表示全部品种。
- 可发布日期：今天和前 3 天；查看日期不能晚于今天。
- 涨跌 =（本次价 − 上一个有数据日期的已发布价）÷ 上一个价，4 位小数；绝对值 > `0.20` 需复核，正好 20% 不复核；无上一个价不复核。
- 价格 >0、最多 2 位小数；单位 `YUAN_PER_KG` 元/千克、`YUAN_PER_HEAD` 元/头、`YUAN_PER_BIRD` 元/只。
- 行状态 `row_status`：`PENDING_REVIEW` 待复核、`PUBLISHED` 已发布、`UNPUBLISHED` 未发布（含退回/当天未录入/已撤销）。
- 复核人不能是录入人；更正待复核时不能是更正人。
- 待复核价格用户端不可见（只读 `PUBLISHED`），因此发布/复核/更正不会改变 `/api/v1/market-prices/*` 的行为。

`MarketPriceRowVO`：

| 字段 | 类型 | 说明 |
|---|---|---|
| config_id | long | 发布配置 |
| price_id | long? | 未发布为空 |
| province_code / province_name | string | 地区 |
| category_id / category_name | long/string | 品类 |
| breed_id / breed_name | long/string | 品种；0 时为“全部品种” |
| price_type / price_type_text | string | `SLAUGHTER/SEEDLING`、出栏价/种苗价 |
| price / price_unit / price_unit_text | decimal/string/string? | 今日价与单位 |
| change_rate | decimal? | 较上一次 |
| prev_price / prev_price_date | decimal/date? | 上一个有数据日期 |
| is_prev_corrected | boolean | 上一个价是否被更正 |
| is_over_threshold | boolean | 涨跌绝对值 >20% |
| row_status / row_status_text | string | 见上 |
| review_kind / review_kind_text | string? | `NEW_PRICE/CORRECTION`，新价/更正 |
| entered_by_name / entered_at | string/datetime? | 录入人 |
| can_review / can_correct | boolean | 当前管理员可复核/可更正 |
| unpublished_text | string? | 过去日期未发布显示“当天未发布” |

### 3.1 ADM-C11 某日价格表

- `GET /admin/v1/market-prices`
- 权限：`WA-C02:VIEW`
- Query：`date`（默认今天，≤今天）、`status`（`ALL/PENDING_REVIEW/PUBLISHED/UNPUBLISHED`，默认 ALL）、`province_code`、`category_id`、`page`、`size`
- 排序：待复核 → 已发布（按配置 sort_no）→ 未发布。
- `tab_counts`：`ALL/PENDING_REVIEW/PUBLISHED/UNPUBLISHED`。
- 响应 `PageVO<MarketPriceRowVO>`。
- 错误：40001“只能查看今天及以前的行情”；40106；40308。

### 3.2 ADM-C12 未发布清单与进度

### 3.5 ADM-C15 行情导入

#### 3.5.1 下载模板

- `GET /admin/v1/market-prices/import-template`
- 权限：`WA-C02:HANDLE`
- 响应：xlsx 文件（`Content-Disposition: attachment; filename*=UTF-8''行情导入模板.xlsx`），不回 JSON。
- 列固定为：`日期、省份、城市、品类、品种、规格、价格、单位、涨跌、来源`；第二个工作表为“填写说明”。
- 模板不写入示例数据行，避免示例被误导入。

#### 3.5.2 导入

- `POST /admin/v1/market-prices/import`（multipart：`file`，xlsx，≤2MB，≤200 行）
- Header：`Idempotency-Key` 可选（带则按管理端幂等规则缓存成功结果）
- 权限：`WA-C02:HANDLE`
- **整文件事务**：先解析并逐行校验；任一行失败则整个文件回滚，返回逐行错误；全部通过后在同一事务写入 `t_market_price`（不另建价格表）。
- 成功响应 data：

```json
{
  "total": 8, "success": 8, "failed": 0,
  "errors": [], "file_name": "10月24日行情.xlsx"
}
```

- 失败响应：HTTP 400、`code=40001`，`data` 为 `{total, success:0, failed, errors:[{row,message}]}`；`row` 为 Excel 行号（表头第 1 行）。整文件已回滚。
- 模板格式错误/超过 2MB/超过 200 行：`40002`“只支持按模板填写的 xlsx 文件，不超过 2MB”或“每次最多导入 200 行”。

逐行校验与映射：

| 列 | 规则 |
|---|---|
| 日期 | 必填；`yyyy-MM-dd` 或 Excel 日期；今天至前 3 天；同一文件可以多天 |
| 省份 | 必填；省份名称（内蒙古、山东等）或 6 位行政区划码；必须能匹配到启用的发布配置 |
| 城市 | 选填，≤20 字；写入备注（现有价格表无城市列） |
| 品类 | 必填；平台启用品类名称 |
| 品种 | 选填；不填/“全部品种”表示 `breed_id=0`；其他按品类内启用品种匹配 |
| 规格 | 选填，≤30 字；可填“出栏价/种苗价”区分同品类两条发布配置；其他文字写入备注（现有价格表无规格列） |
| 价格 | 必填；>0、最多 2 位小数 |
| 单位 | 选填；`元/千克、元/头、元/只` 或 `YUAN_PER_KG/YUAN_PER_HEAD/YUAN_PER_BIRD`；留空取配置默认单位 |
| 涨跌 | 忽略填写内容，由系统按上一个有数据日期的已发布价重算 |
| 来源 | 选填，≤30 字；留空记为 `IMPORT` |

去重与状态：

- 同一天同地区同品类同品种同价格类型（现有唯一键）= 一行；`规格` 相同再导入返回行错误“同一天同地区同品类同规格的价格已存在”。因为 `t_market_price` 没有规格列，同品类多规格暂不能同时入库（见 5.2 第 7 条）。
- 已存在 `PUBLISHED/PENDING_REVIEW` 的行不能重复导入；`RETURNED/OFFLINE` 行允许覆盖并清空复核信息。
- 涨跌绝对值 >20% 的行按与 ADM-C14 相同规则进入 `PENDING_REVIEW`，否则 `PUBLISHED`；补录过去日期后按既有逻辑重算后续日期的 `prev_price/change_rate`。
- 写一条 `MARKET_PRICE / IMPORT` 操作日志（行数、文件名），不输出逐行明文。

### 4.9 ADM-C65 导出问答记录

- `POST /admin/v1/ai-qa/export`
- 权限：`WA-C05:HANDLE`
- Body 同 ADM-C58 筛选条件。
- 响应同 ADM-C10：`{file_id,file_name,status,url,row_count}`。
- 列：问题、养殖场、提问人、关联批次、回答类型、评价、处理状态、提问时间。不导出批次快照与回答全文。>5 万行返回 40001。
- 说明：同步生成 xlsx 并写 `t_file`（scene=EXPORT）。

### 4.10 转为知识补充任务（ADM-C55 的 WA-C05 入口）

- `POST /admin/v1/ai-qa/{message_id}/task`
- 权限：`WA-C05:HANDLE` 或 `WA-C04:HANDLE`
- Request：

```json
{
  "title": "猪舍熏蒸消毒",
  "mode": "NEW_ENTRY",
  "target_knowledge_id": null,
  "category_id": 202,
  "assignee_id": 3,
  "due_date": "2026-10-26",
  "points": "写清空舍熏蒸、熏后通风时间与带猪驱蚊方法",
  "similar_count": 14
}
```

- 行为：校验被指派人 `WA-C04:HANDLE`、期望完成 ≥ 今天；`handle_status` 从 `PENDING` 改为 `TASKED`（`CORRECTED` 不改）；写 `t_ai_qa_review.last_action=TASK`；给被指派人写管理端消息 `KNOWLEDGE_TASK_ASSIGNED`。
- 响应：`{ "id": null, "title": "猪舍熏蒸消毒", "status": "PENDING" }`。
- **限制**：`t_knowledge_task` 表归管理端-02 下篇 / 知识库模块（WA-C04），本分支未建该表，因此 `id` 暂为 `null`；任务出现在 WA-C04“补充任务”标签页需要 C04 分支合并后把此处创建逻辑替换为 `KnowledgeTaskService.create`。当前已保证管理端消息、处理状态与留痕可用。
- 错误：40001“请填写任务标题，最多 40 字”“被指派人没有知识库处理权限”“期望完成日期不能早于今天”；40903“这条问答已有待处理的补充任务”；40401。

### 5.2 与文档的差异

1. **通知分发**：文档为事务提交后异步分发；当前在 Controller 的事务提交后同步调用 `NoticeDispatchService.dispatch`，接口返回前完成写消息，便于联调与验收。定时任务 `NoticeSendJob` 仍每分钟补发。
2. **推送记录**：`t_notice_recipient.push_record_id` 暂为空；推送由 `MessageService` 写 `t_push_record`，未回填到送达明细。阅读统计直接从 `t_message.read_at` 与 `t_push_record.clicked_at` 读取，不影响阅读率。
3. **行情配置**：沿用模块10 已有的 `t_market_price_config.status = ENABLED/DISABLED`，接口输出 `is_enabled`；新增 `default_unit` 列。
4. **行情价格**：沿用模块10 `t_market_price.corrected/corrected_at/source`，接口输出 `is_corrected/data_source`；新增复核、涨跌、版本等列。
5. **AI 更正**：在原 `t_ai_correction` 上补 `session_id/farm_id/user_id/published_flag/first_published_at/published_by/withdrawn_*` 与 `version`；用户端 `AiCorrectionMapper` 仍按 `message_id + status=PUBLISHED` 读取，行为不变。
6. **导出**：未接入 ADM-S37 异步任务轮询，直接返回 `url`；前端可用 `url` 下载，`file_id` 便于后续切换。
7. **C15 导入落库**：文档原设计为“只预览不入库”，本次按验收要求改为整文件事务直接入库；模板列使用验收给定的 10 列（日期、省份、城市、品类、品种、规格、价格、单位、涨跌、来源），不包含原文档的“价格类型/今日价/计价单位”三列。现有 `t_market_price` 没有城市、规格列，城市/规格写入 `remark`，同一天同地区同品类同品种同价格类型仍只能一行；若产品要求同品类多规格并存，需另加列与唯一键迁移。
8. **C15 涨跌列**：模板保留“涨跌”列但导入时忽略；实际涨跌由 `MarketPriceCalculator` 按上一个有数据日期的已发布价重算，避免手工涨跌与复核阈值不一致。
