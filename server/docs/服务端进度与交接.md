## 四、本机运行

1. 启动中间件：`server/tools/start-dev.ps1`（Redis 6379、MinIO 9000 / 9001）；停止用 `stop-dev.ps1`。免安装包不进 git，换电脑需按 `server/tools/README.md` 重新下载。
2. 环境变量：复制 `server/.env.example` 为 `server/.env.local` 并填写（密钥单独传，不进 git、不发群）。本机 MySQL 9.5 的库名 zhimu。
3. 启动：在 server 目录执行 `mvn -pl zhimu-app -am spring-boot:run`；接口文档 http://127.0.0.1:8080/swagger-ui.html。
4. 测试：`mvn -q -B verify`（默认连本机 MySQL 的 `zhimu_test` 与 Redis database 15；并行开发用 `TEST_DB_NAME`、`TEST_REDIS_DATABASE` 覆盖，见《服务端开发约定.md》第六节）。

## 七、工作方式（接手人请保持）

- 只在 `server/` 下工作，**不改 App 的任何代码**；分支 `feature/server`。
- 服务端文档与 App 冲突时，**优先兼容 App**；编码前先把冲突列出来交负责人选择，选择结果写进《服务端开发约定.md》第七节。
- 每批完成后停下来验收：合并、`mvn -q -B verify` 全部通过、启动冒烟，再进入下一批。
- 每批开工前先定跨模块接口（放在各模块的 api 包），并行开发时各人只改自己的包和分配好的 Flyway 版本号（见《服务端开发约定.md》第五节）。
- App 联调前要关掉 App 调试包的测试直连：清空 local.properties 中的 ai.dashscopeKey、ai.deepseekKey、aliyun.accessKeyId、aliyun.accessKeySecret，并设置 zmt.baseUrl、zmt.useMock=false（见 docs/项目交接与三端联调说明.md 第五节）。
