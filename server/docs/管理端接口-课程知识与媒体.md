# 管理端接口：养殖课堂、知识库与媒体上传/转码

> 范围：Web 管理端 WA-C03 养殖课堂管理、WA-C04 知识库管理，以及两者共用的管理端媒体能力。
> 依据：`管理端-02-内容运营-服务端技术准备文档（下）` ADM-C22–C56、`管理端-04-用户与系统-服务端技术准备文档` ADM-S34–S39。
> 实现分支：`web/admin-media`；Flyway：`V1_22_3__admin_course_media.sql`。
> 所有接口统一 `/admin/v1` 前缀、`ApiResponse<T>` 响应、JSON snake_case、北京时间；分页 page 从 1 开始，size 默认 20、最大 100（C23 默认 10）。

## 一、权限

| 权限点 | 能力 |
|---|---|
| `WA-C03:VIEW` | 查看课程、专题、分类、课程数据、转码进度 |
| `WA-C03:HANDLE` | 上传、新建、编辑、上下架、删除草稿、重试转码、专题与分类维护、导出 |
| `WA-C04:VIEW` | 查看知识条目、版本、补充任务 |
| `WA-C04:HANDLE` | 新建、编辑、发布、回退、上下架条目，创建与关闭补充任务 |
| `WA-C01:HANDLE` | ADM-S34 通知配图（NOTICE_IMAGE）上传 |
| `WA-C01/03/04:VIEW` | ADM-S37 按场景查看文件；ADM-S39 下载导出文件 |

说明：

- 分类同时服务课程与知识库：ADM-C40 需要 C03 或 C04 的 VIEW，C41–C43 需要任一 HANDLE。
- 课程列表 ADM-C23 允许 `WA-C03:VIEW` 或 `WA-C04:VIEW`（知识库编辑抽屉插入视频时复用）。
- 文件接口的类级权限只是“任一内容运营权限”，Service 会按 `scene` 再校验对应页面权限：
  `NOTICE_IMAGE→WA-C01`、`COURSE_VIDEO/COURSE_COVER/TOPIC_COVER→WA-C03`、`KNOWLEDGE_MEDIA→WA-C04`。
  无权限统一 40308“你没有该页面的操作权限，如需处理请联系超级管理员”。

## 三、ADM-C22–C35 养殖课堂

### ADM-C22 课程指标卡与导航计数

`GET /admin/v1/courses/summary`，无参数。

```json
{
  "code": 0, "message": "ok",
  "data": {
    "on_shelf_count": 46, "topic_count": 8, "category_count": 4,
    "plays_30d": 28640, "viewers_30d": 9812, "avg_finish_rate": 0.5830,
    "transcoding_count": 1, "failed_count": 1,
    "nav": {
      "total": 52,
      "topics": [{"id": 7001, "name": "仔猪腹泻防控", "on_shelf_count": 6}],
      "categories": [{"id": 5102, "name": "疾病防治", "count": 16}]
    }
  }
}
```

口径：近 30 天 = 今天之前 30 个完整自然日；播放次数取播放记录，观看人数按账号去重；平均完播率 = 有观看人数的已上架课程完播率的算术平均；`transcoding_count` 含 WAITING、PROCESSING。当前按实时数据计算，不缓存（文档建议的 10 分钟缓存未做）。

### ADM-C23 课程列表

`GET /admin/v1/courses`

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| topic_id | long | 否 | 选专题时按 `section_no` 升序，否则按更新时间倒序 |
| category_id | long | 否 | 分类筛选 |
| status | string | 否 | `ALL`/空=全部；ON_SHELF / OFF_SHELF / DRAFT |
| transcode_status | string | 否 | NONE / WAITING / PROCESSING / SUCCESS / FAILED |
| keyword | string | 否 | ≤30 字，匹配标题或专题名 |
| page / size | int | 否 | 默认 1 / 10，最大 100 |

响应 `PageVO<CourseRowVO>`，`tab_counts` 为 `ALL / ON_SHELF / OFF_SHELF / DRAFT`（受专题、分类、转码、关键词影响，不受状态影响）。

  "data": {

      "category_id": 5102, "category_name": "疾病防治",
      "topic_id": 7001, "topic_name": "仔猪腹泻防控", "section_no": 2,
      "upload_status": "READY", "transcode_status": "SUCCESS", "transcode_status_text": "转码完成",
      "p720": {"status": "SUCCESS", "progress": 1.0000},

      "status": "ON_SHELF", "status_text": "已上架",

### ADM-C26 新建课程 / ADM-C27 编辑课程

`POST /admin/v1/courses`（要求 `Idempotency-Key`）；`PUT /admin/v1/courses/{id}`。

请求体：

| 字段 | 类型 | 必填 | 规则 |
|---|---|---|---|
| submit_action | string | 是 | DRAFT / ON_SHELF；C27 不传时：当前已上架按 ON_SHELF，否则 DRAFT |
| title | string | 上架时是 | 1–30 字；有视频且为空时取文件名去扩展名后前 30 字 |
| category_id | long | 上架时是 | 启用分类；草稿为空时默认第一个启用分类 |
| topic_id | long | 否 | 存在的专题 |
| section_no | int | 加入专题时是 | ≥1；与已有节次冲突时其后课程顺延 |
| applicable_category_ids | long[] | 否 | 启用的品类，≤10；空 = 全部品类 |
| knowledge_id | long | 否 | 必须为已上架知识条目 |
| intro | string | 否 | ≤200 字 |
| video_file_id | long | 上架时是 | 管理员上传、scene=COURSE_VIDEO、上传状态不为 FAILED；已上架课程不能更换 |
| cover_source | string | 上架时是 | AUTO / UPLOAD |
| cover_file_id | long | 上架时是 | AUTO：须为该视频的封面候选（parent_file_id）；UPLOAD：COURSE_COVER、JPG/PNG ≤5MB |
| version | int | C27 是 | 乐观锁 |

响应 `CourseVO`：

```json
{"code":0,"message":"已上架，用户端立即可见","data":{
  "id":6102,"status":"ON_SHELF","transcode_status":"SUCCESS","shifted_count":0,"version":1
}}
```

错误：40001 字段校验（文案：请填写课程标题 / 标题不能超过 30 字 / 请选择分类 / 加入专题时请填写节次 / 关联的知识条目未上架）；40002 封面类型或大小不符；40903 未转码完成或缺封面 / 已上架课程更换视频；40902 版本冲突。

### ADM-C28 课程详情

`GET /admin/v1/courses/{id}`，返回 `CourseDetailVO` = `CourseRowVO` 全部字段 +：

| 字段 | 说明 |
|---|---|
| intro | 简介 |
| knowledge_id、knowledge_title | 关联知识条目 |
| applicable_category_ids | 适用品类，空数组 = 全部 |
| video | `{file_id, original_name, file_size, duration_sec, width, height, uploaded_at, upload_status, transcode_status}` |
| transcode_error | 转码失败原因 |
| cover_file_id、cover_source | 封面 |
| cover_candidates | `[{file_id,url}]`，转码完成后 3 张 |
| on_shelf_at、on_shelf_by_name、off_shelf_at、off_reason | 上下架信息 |
| version | 乐观锁 |

### ADM-C30–C35 状态、数据与导出

| 接口 | 请求 | 前置/规则 | 响应 |
|---|---|---|---|
| C30 `POST /courses/{id}/transcode/retry` | 无 | transcode_status=FAILED；原片对象不存在返回 41001“原片已清理，请重新上传” | `TranscodeStateVO`，message“已重新开始转码” |
| C31 `POST /courses/{id}/on-shelf` | `{version}` | DRAFT/OFF_SHELF；转码两档 SUCCESS、已选封面、标题、启用分类；专题中有节次 | `CourseVO` |
| C32 `POST /courses/{id}/off-shelf` | `{off_reason,version}` | ON_SHELF；off_reason ≤100 必填 | `CourseVO` |
| C33 `DELETE /courses/{id}?version=` | 查询参数 version | 仅 DRAFT；释放原片与封面绑定 | data 为 null |
| C34 `GET /courses/{id}/stats` | 无 | 草稿返回空统计 | `CourseStatsVO` |
| C35 `POST /courses/{id}/stats/export` | 无 | 非草稿；同步生成 xlsx，返回 10 分钟下载地址 | `{file_id,file_name,status,row_count,url,expire_at}` |

草稿不存在时 `draft` 省略；`draft_owner` 只在草稿保存人不是当前管理员时返回。

### ADM-C46 新建 / C47 保存草稿

`POST /admin/v1/knowledge`（要求 Idempotency-Key）；`PUT /admin/v1/knowledge/{id}/draft`。

| 字段 | 类型 | 必填 | 规则 |
|---|---|---|---|
| title | string | 是 | 1–40 字 |
| category_id | long | 是 | 启用分类 |
| source_type | string | C46 是 | PLATFORM / DISEASE；DRUG_CATALOG 只能系统同步 |
| is_major_epidemic | boolean | 否 | 只对 DISEASE 有效 |
| display_type | string | 否 | STANDARD / ARTICLE；不传时 DISEASE→STANDARD、PLATFORM→ARTICLE |
| applicable_category_ids | long[] | 否 | 空 = 全部品类 |
| keywords | string[] | 否 | ≤8 个，每个 ≤10 字，自动去重 |
| content | string | 是 | 受限 HTML，纯文字 1–20000 字；视频卡只能引用已上架课程，图片须为 KNOWLEDGE_MEDIA READY 文件 |
| source_task_id | long | 否 | 待处理任务 |

响应 `KnowledgeVO`：`{id,status,online_version_no,new_version_no,affected_answers_30d,version}`。

错误：40001 请填写标题 / 关键词最多 8 个 / 请填写正文 / 正文需为 1–20000 字；40303 兽药目录同步的条目请在兽药疫苗目录中维护；40902 版本冲突。

### ADM-C48 发布新版本

`POST /admin/v1/knowledge/{id}/publish`，`{change_note, version}`。

规则：必须有草稿；`change_note` 必填；新版本号 = 已发布最大版本号 + 1；旧线上版本置 SUPERSEDED；条目为 DRAFT 时发布后变 ON_SHELF，已下架条目发布后仍为 OFF_SHELF；段落整体重建并标记 `is_online`；同步适用品类；完成目标补充任务。

响应 message：“已发布版本 4，AI 将按新版本回答”；data 含 `online_version_no`。

错误：40004 请填写修改说明；40903 没有可发布的草稿；40303 兽药目录同步；40902 版本冲突。

### 6.3 ADM-S35 分片初始化 / 续传

`POST /admin/v1/files/multipart`（`Idempotency-Key` 可选；续传时可不带）

```json
{"scene":"COURSE_VIDEO","original_name":"冬季鸡舍通风与保温.mp4",
 "file_size":299892736,"mime_type":"video/mp4","file_id":null}
```

响应：

```json

  "file_id":70123,"part_size":10485760,"part_count":29,
  "original_name":"冬季鸡舍通风与保温.mp4",

```

续传：带 `file_id` 重新调用，`uploaded_parts` 列出已上传分片，`part_urls` 只返回缺失分片（仍返回全部 `part_count`）。

### 6.4 浏览器直传与 CORS

推荐前端直接用 `part_urls[].url` 发 `PUT`（每片 10MB），从响应头取 `ETag` 后调用 DI-S36。MinIO 需要允许管理端站点跨源 PUT 并暴露 ETag，例如：

```bash
mc admin config set local api cors_allow_origin="http://localhost:5173,http://127.0.0.1:5173"
# 修改后重启 MinIO；响应需带 Access-Control-Expose-Headers: ETag
```

若环境无法配置 CORS，使用补口扩展 **ADM-S36b** 逐片上传到应用服务器：

`POST /admin/v1/files/{id}/multipart/part?part_no=1`，multipart 字段 `file`（二进制分片），返回 `{"part_no":1,"etag":"..."}`。两种方式得到的 ETag 都可用于合并；同一上传任务不要混用。

### 6.5 ADM-S36 合并分片并进入转码

`POST /admin/v1/files/{id}/multipart/complete`

```json
{"parts":[{"part_no":1,"etag":"\"e1a...\""},{"part_no":2,"etag":"\"b2c...\""}]}
```

服务端校验分片编号连续齐全、ETag 与 MinIO 已上传分片一致 → 合并 → 校验大小 → ffprobe 读时长（>30 分钟删除并 40003）→ `upload_status=READY`、`transcode_status=WAITING`、插入 HLS_720P/HLS_480P 两条 WAITING 派生版本 → 异步转码。

成功响应 `AdminFileVO`（`transcode_status=WAITING`），message“上传完成，已开始转码”。错误：40001“分片不完整，请重新上传”；40003“只支持 MP4 和 MOV，不超过 2GB、30 分钟”；40903“文件已处理，请刷新”。

### 6.6 ADM-S37 文件状态与转码进度

`GET /admin/v1/files/{id}`

```json
{
  "file_id":70123,"scene":"COURSE_VIDEO","original_name":"冬季鸡舍通风与保温.mp4",
  "file_size":299892736,"mime_type":"video/mp4","duration_sec":408,
  "width":1920,"height":1080,"upload_status":"READY",
  "transcode_status":"PROCESSING","status":"PROCESSING","transcode_error":null,
  "url":"http://.../raw/...?X-Amz-...",
  "cover_file_id":70200,"cover_url":"http://127.0.0.1:9000/zmt-course/cover/70123/1.jpg",
  "hls_url":null,
  "variants":[
    {"variant_code":"HLS_720P","status":"PROCESSING","progress":0.6200,"width":1280,"height":720,"file_size":null,"error_message":null},
    {"variant_code":"HLS_480P","status":"WAITING","progress":0.0000,"width":854,"height":480,"file_size":null,"error_message":null}
  ],
  "cover_candidates":[{"file_id":70200,"url":"http://.../cover/70123/1.jpg"}],
  "created_at":"2026-10-23 09:40:00"

```

`status`：UPLOADING / PROCESSING / READY / FAILED（FileVO 口径）；转码完成后 `hls_url = {HLS_BASE_URL}/{file_id}/index.m3u8`。

### 6.7 ADM-S38 重新转码

`POST /admin/v1/files/{id}/transcode`：transcode_status 必须 FAILED，重置失败派生版本为 WAITING 并重新入队；成功 message“已重新开始转码”。40903“只有转码失败的视频可以重新转码”；41001“原片已清理，请重新上传”。

失败重试策略：初始 1 次 + 自动重试 3 次，间隔 1/5/15 分钟；仍失败写 `t_file.transcode_error`、派生版本 FAILED，并给上传人写 `TRANSCODE_FAILED` 站内消息。重启后 `TranscodeDispatchJob` 每分钟补偿 WAITING 任务、重置超过 10 分钟无进度的 PROCESSING。

### 6.8 ADM-S39 下载

`GET /admin/v1/files/{id}/download`：返回 `{file_id,file_name,url,expire_at}`，url 10 分钟有效。导出文件仅生成人/超管可下载；过期 41001“文件已过期，请重新导出”。

### 6.9 用户端一致性

- 课程上架后写 `t_course_media` 两行 HLS 地址（720P/480P），用户端 `GET /api/v1/courses/{id}` 直接可播；HLS 主播放列表 `hls/{file_id}/index.m3u8` 也生成。
- 课程封面写公开地址 `cover/{file_id}/n.jpg` 到 `t_course.cover_url`；专题封面同理。
- 知识发布把段落写入 `t_ai_knowledge_paragraph`（`is_online=1`、`content_html`、`para_key`），并回写 `t_ai_knowledge` 的标题/分类/版本/关键词/`has_video`；用户端 `GET /api/v1/knowledge-items/{id}` 无需改动即可读到新版本。
- 下架时课程/知识的状态与 `is_online` 同步变更，用户端提示“这个视频已下架”“这条知识已下架，不能查看原文”。

## 九、未实现 / 降级项（给前端与主控）

1. **AI 问答与更正 ADM-C57–C65 不在本分支范围**；只实现了从问答/更正创建知识补充任务所需的 ADM-C55（不写 `t_ai_qa_review`，该表尚未建）。
2. **统计缓存与 00:30 每日汇总任务未实现**：ADM-C22/C34 按播放记录与学习进度实时计算；`t_course_stat_daily` 表已建，任务留待后续补。数据量大时需补缓存/汇总。
3. **C35 导出同步生成**：当前接口内生成 xlsx 并返回 10 分钟地址；文档中的“异步生成后轮询 S37”可以兼容（生成后 status=READY），但不会后台排队。
4. **ADM-S34 只支持 JPG/PNG**：未做图片压缩；知识图片放私有桶 `knowledge_media/` 前缀并单独开放匿名只读，便于用户端原文长期显示（与文档“私有桶签名地址”略有差异）。
5. **视频直传依赖 MinIO CORS**：提供 ADM-S36b 服务端代传分片作为无 CORS 环境的兼容方案。
6. **封面候选尺寸**：封面候选文件写入 `t_file` 时宽高固定记为 1280×720（仅用于列表展示，不影响播放）。
7. 旧课程（V1_11 示例数据）没有 `video_file_id`，转码状态回填为 SUCCESS，可正常在列表显示；再次编辑上架前需要重新上传视频并绑定，否则上架校验会提示未转码完成。
8. `ADM-C66` 删除知识草稿为补口扩展，服务端文档原无编号。
